# 13 Development-only helpers

Status: open
Blocked by: 12

## Scope

- A readout of how many Chime Slots are scheduled with the OS.
- A "Chime in 10 s" action that schedules one Chime with the current Chime Sound.
- Both rendered only in development builds, absent from release builds.

## Acceptance

- Both helpers work in a dev build and do not appear in a release build.
